# Первые шаги в офисе

1. [Открыть офис](1-ustanovka.md) в выбранном клиенте.
2. [Подготовить знакомство](2-podgotovka.md), если хотите; можно сразу работать.
3. [Пройти восемь этапов](3-karta-stroyki.md) в своём темпе.

Офис хранит память в этой папке, а не в одном чате. Для смены клиента открывайте ту же папку через office-start.py; копию офиса заново не создавайте. Закрытые этапы и подтверждённые факты остаются в общих файлах.

Модельная приёмка этой версии проведена в Codex CLI на macOS. Claude Code в итоговой приёмке SKIPPED по решению владельца; совместимые инструкции и настройки включены. Это не обещание проверенной работы на каждом клиенте и ОС.
