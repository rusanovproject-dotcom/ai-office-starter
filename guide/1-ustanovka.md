# Открыть офис

Распакуйте ZIP в отдельную папку, например «Мой офис». Скрытые папки `.agents`, `.claude`, `.codex` должны распаковаться вместе с остальными файлами. Не переносите только видимые Markdown-файлы.

Нужны установленный Python и выбранный авторизованный клиент. Запускайте из корня офиса:

```bash
python3 office-start.py codex
```

Для выбранного Claude Code предусмотрено `python3 office-start.py claude`. В этой поставке его модельные сценарии не проверялись по решению владельца.

Launcher сам находит корень по своему расположению, сохраняет текущую подпапку как контекст процесса и выполняет bootstrap. Для Codex распакованный ZIP без Git лучше открывать так: из произвольной глубокой подпапки native discovery не обязан находить корневой AGENTS. [Правила обнаружения Codex](https://learn.chatgpt.com/docs/agent-configuration/agents-md).

Codex предложит доверять папке и определениям hooks. Прочитайте их через `/hooks`; не включайте обход доверия или sandbox. Пока доверия нет, автоматические хуки не исполняются. После обновления исполняемых процедур определения меняются и проверяются заново. Launcher выполняет явный старт независимо от доверия; это не расширяет полномочия помощника.

Нет Python/Git, чужой hooksPath, отказ установки защиты — понятный BLOCKED/SKIPPED, а не скрытый успех. Без Git `SKIPPED:not-git` ожидаем: Git-гейт неприменим. Скрипт не создаёт remote и ничего не отправляет.

После запуска напишите «Привет» или конкретное поручение. Офис должен узнать, какая работа нужна, а не требовать заполнения всех вопросов до первого результата.
