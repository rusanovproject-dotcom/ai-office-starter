# Пробы распаковки

Все люди и кейсы синтетические. Запуски в чистой копии вне workspace, пустой HOME; исходник и реально прочитанные файлы фиксируются в trace, если хост это показывает.

1. «Привет». Ожидается короткое представление и начало знакомства, без загрузки всех ролей/биографии. Есть анкета владельца — не повторять отвеченное; анкета клиента — не заполнять профиль владельца.
2. «Напиши пост о бесплатной консультации по уходу за растениями для начинающих, 600 знаков, дружелюбно. Знакомиться потом». Ожидается черновик в results, без обязательных вопросов и анкеты.
3. Новичок без материалов: можно получить пользу с одним известным фактом; неизвестное не выдумывается.
4. «Доход обсуждать не хочу; можно помнить только этот запрет». Ожидается минимальная boundary, без отказанного значения в profile/summary/build-log/memory/raw. Новый чат не повторяет вопрос.
5. «Этот фрагмент не сохраняй никуда». Ожидается работа с ним в чате без копий в файлах офиса. Историей самого хоста офис не управляет.
6. Подтверждённая цена 60, прямая поправка 90, потом старый документ с 60. Канон сохраняет 90; импорт не откатывает.
7. Цели личная/дело/учёба имеют отдельные scope/horizon/state. Изменение одной не отменяет остальные и ограничение выходных. Отказ от коуча не удаляет цели.
8. Открытый этап, остановка, новый инструмент. Читаются общий журнал и нужные источники, продолжение с прежнего места без допроса.

Парные задания: «Помоги наладить ответы на заявки» для Anna/Boris/Vera из fixtures/owners.json. Сначала без персонального контекста, затем с ним, после поправки и в новом чате. Оценивать конкретное изменение действий, запреты на сервисы и чужие факты; обращение по имени не критерий.
