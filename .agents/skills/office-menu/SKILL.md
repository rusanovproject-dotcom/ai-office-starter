# Что может офис

Проверь team/registry.json и канонические навыки. Покажи несколько дел языком результата, опираясь на контекст задачи: создать пост/письмо/локальную страницу, разложить клиентов, завести проект, организовать работу, собрать сотрудника. Draft не выдавай за активного. Не обещай API, расшифровку, отправку и фоновые процессы без работающих инструментов.

При потребности в новом сотруднике — office-hire: конкретная задача, источники, draft, проба, подтверждение и активация. Стартовая цепочка найма работает локально; внешний каталог не нужен. Имя и роль выбираются по предмету работы, личные настройки остаются общими для всех.
