# Проекты и люди

Сначала выбери объект: явный проект/путь, затем подтверждённый текущий контекст. «Для А как в Б» означает А, Б — только допустимый референс. При существенной неоднозначности клиента уточни объект, не внутреннего исполнителя. Имя сотрудника и явный навык сохраняются вместе. Читай локальные AGENTS перед работой.

Для проекта прочитай projects/AGENTS.md и _project-template.md. Используй `python3 scripts/office/projects.py --help`: единая процедура создаёт projects/<slug>/map.md, AGENTS.md с областью, источниками, доступами, критериями приёмки и ссылкой на корневой контекст; CLAUDE.md импортирует @AGENTS.md. Карты/INDEX обновляются тем же путём. Существующий проект не перезаписывай. Не приписывай учебному проекту чужой бизнес.

Для клиентов: clients/AGENTS.md, одна карточка на человека, строка в INDEX. Сохраняй только разрешённое. При просьбе одновременно разложить клиентов и написать пост выполни оба результата с отдельным контекстом; клиентские сведения в пост не переносятся без разрешения. Покажи получившийся результат, инициатор принимает работу до конца.
