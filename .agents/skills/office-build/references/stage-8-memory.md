# Этап 8 — Память и завершение

Покажи человеку карту офиса ссылками в MAP.md: профиль, цели, дело, проекты, команда, результаты. Объясни, что факты исправляются в каноне, а история не откатывает их. Не обещай сохранение запрещённых сведений или управление историей чата хоста.

Прочитай core Риты, создай персональную card и память с нужными сценариями, зарегистрируй отдельно имя, алиасы и роль. Сохрани draft до проверенной пробы и подтверждения владельца. Выполни пример уборки без удаления реальных данных: исправь ссылку в синтетическом индексе, проверь целевой файл и сохрани разрешённый результат локально, например `results/rita-trial.md`. Критерий: «ссылки ведут к существующим файлам, исходные данные сохранены». Запиши оценку по нему и принятое решение в разрешённую память роли.

После подтверждения результата владельцем активируй через `python3 scripts/office/hire.py activate --id rita`, JSON через stdin: `task`, `output` (резюме), `artifact` (относительный путь существующего непустого результата), `criterion`, `assessment`, `confirmed: true`. Не выдумывай подтверждение и не спрашивай его второй раз, если уже получено. Без подтверждения или разрешённого артефакта роль остаётся draft, этап открыт. Удаление согласуется отдельно; архив не равен проверенной резервной копии.

После активации проверь `bash scripts/office/stage-check.sh 8` (требует active), затем audit. Только после подтверждённых результатов всех непропущенных этапов пометь `СТРОЙКА ЗАВЕРШЕНА`. Покажи, как продолжать в любом клиенте из того же корня. Нельзя говорить, что переключение инструментов проверено, если выполнена только проверка файлов.
