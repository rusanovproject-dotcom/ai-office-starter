# Этап 7 — Проекты и люди

Одна механика с office-project-add: прочитай его SKILL.md и используй scripts/office/projects.py. Новый проект получает map.md, AGENTS.md (предмет/источники/доступы/приёмка/контекст), CLAUDE.md с @AGENTS.md и строки в картах. Если несколько проектов — выбери реальный объект, пример другого проекта не переключает цель. Не создавай вымышленный бизнес для человека в найме; возможен учебный проект с его собственным критерием завершения.

Клиентов может не быть. Если есть, прочитай clients/AGENTS.md; одна карточка и строка в INDEX, без смешения людей. Журнал хранит ссылки, не дубли карточек. Проверь `bash scripts/office/stage-check.sh 7`, покажи результат и закрой этап.
