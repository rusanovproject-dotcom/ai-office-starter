# Контекст, поиск по базе и дообучение

Эти слова обозначают разные механизмы, поэтому сначала выясни, что нужно для задачи.
Не оценивай конкретное предложение по одному слову «обучение» или цене.

- **Инструкции и контекст:** модель получает правила и нужные сведения во время запроса.
  В этом пакете так используются `AGENTS.md`, навыки и прочитанные файлы памяти.
- **Поиск по базе:** система находит подходящие материалы и передаёт их модели для ответа.
  Наличие файлов само по себе не означает настроенный поисковый индекс или RAG.
- **Дообучение:** меняются параметры модели на подготовленных данных. Сохранение профиля
  в Markdown в этом офисе такой операции не выполняет.

Для вопроса о текущей цене нужен проверенный источник факта. Красивый стиль ответа
сам по себе не доказывает актуальность. Для повторяемой процедуры могут помочь ясные
инструкции и примеры; для большого корпуса сначала проверяют, как находятся нужные
сведения. Выбор дообучения требует отдельной задачи, данных и проверки качества.

Полезные вопросы к конкретной реализации: какой вход она получает, откуда берёт факты,
что именно меняет, где хранит данные и как проверяется результат на примере. Без ответа
не обещай ни эквивалентность решений, ни фиксированную экономию.

Основание для описания этого пакета: корневой `AGENTS.md`; `README.md`;
`scripts/office/personalize.py`. Поиск/RAG и дообучение не входят в заявленный launcher
этого шаблона; возможности внешнего продукта проверяются отдельно по его источникам.
