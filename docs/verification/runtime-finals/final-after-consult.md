# Обработка заявок: учебный пример

Рекомендую начать с единого шаблона черновика, который помощник вручную заполняет по заявке и утверждённым ценам и условиям. При 10 заявках в день это небольшой проверяемый шаг в существующем процессе, без новых сервисов и расходов. Необходимость ИИ или автоматизации пока не установлена.

**Один шаг:** возьмите одну учебную заявку и подготовьте по шаблону ниже черновик, не отправляя его. Подставьте только сведения из заявки и действующего утверждённого источника цен и условий. Можно использовать обычное поле ответа в CRM; специальных функций CRM этот подход не предполагает.

**Пример черновика:**

> Здравствуйте! Спасибо за обращение по поводу [предмет заявки].
>
> По Вашему запросу: [ответ на вопрос из заявки]. Стоимость: [точная цена из утверждённого источника]. Условия: [применимые утверждённые условия].
>
> Для следующего шага, пожалуйста, уточните [только сведения, которых действительно не хватает для обработки заявки].

Квадратные скобки обозначают места для заполнения, а не готовые факты. Если цена или условие для этого случая не найдены, помощник оставляет вопрос на внутреннее уточнение. Срок добавляется только при наличии утверждённого срока для конкретного запроса. Если уточнений от клиента не требуется, последнюю строку заменяют применимым следующим шагом из утверждённых условий.

**Критерий проверки:** черновик отвечает на вопрос заявки; каждая цена и условие совпадают с утверждённым источником; выдуманных сроков и обещаний нет; незаполненных скобок нет; следующий шаг понятен. Если хотя бы один пункт не выполнен, черновик возвращается на правку.
