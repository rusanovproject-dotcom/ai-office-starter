# Фактические поведенческие пробы Codex

Codex CLI 0.166.0, macOS arm64. Восемь реальных запусков, все exit 0; timeout не было. Исходный репозиторий этой проверкой не менялся. Использованы пустые HOME и CODEX_HOME, --no-daemon, --ignore-user-config, --ephemeral и sandbox workspace-write. Авторизация использована через временный symlink: содержимое не читалось и не печаталось, все ссылки удалены. Обход доверия хукам и sandbox не применялся.

Финалы и raw JSONL сохранены по testcase; точные SHA256 исходников — source-hashes.json, команды чтения — observations.json. Нативная автозагрузка AGENTS не имеет отдельного события, поэтому явное чтение корня не утверждается. Версия модели не выведена в captured JSONL; использован CLI default без pin.

Ограничения: Claude и смена Codex ↔ Claude этим набором не проверены; lifecycle и trust — отдельная проба. В чужом кейсе не было конкретных сумм, поэтому перенос конкретной суммы не проверен. Реальная CRM, внешняя отправка и публикация не использовались. Одна выборка на условие; статистическая устойчивость не измерялась.
