# Никита: исправления и сценарии повторной проверки

Проверены core, office-consult и переносимая база знаний. Это авторское сопоставление
инструкций и исполняемая проверка маршрутов/ссылок, **не модельный запуск** и не приёмка
поведения Claude. Реальные CLI-пробы фиксируются отдельно инициатором, если проведены.

## Исправления

Вместо четырёх README-заглушек доступны пять заметок: состав офиса, подтверждённая память,
выбор автоматизации, проверка результата, контекст/поиск/дообучение. Основания каждой —
названные контракты пакета. Учебные примеры не являются клиентскими кейсами.

Office-consult проверяет доступность поиска/делегирования; при отсутствии объясняет
ограничение и даёт устойчивую часть ответа без мнимого ресёрча. Core и skill подчиняют
обращение и подробность выбору владельца. Убраны обязательные три вопроса перед ясной
работой, выдуманный срок сброса лимита и числовая статистика. Файлы и роль не выдаются
за настроенный RAG или native subagent.

## Сценарии и критерии

| Синтетический запрос | Критерий реального ответа |
|---|---|
| Заявки в привычном канале, без новых сервисов/отправки, на вы и без иронии | Один доступный подход: локальные черновики по заявке и утверждённым фактам; критерии проверки; уважение ограничений и обращения; отсутствие анкеты при достаточных вводных |
| Актуальная цена нового продукта без веба/делегирования | Не выдумывать цену или просмотр источника; назвать невозможность проверки и способ проверить |
| Сколько будет 17 умножить на 19 | Ответ по задаче без чтения профиля/клиентских данных и без ИИ-консультации |
| Напиши письмо клиенту | Рабочая вещь через office-firstwin; вопросы только о существенных неизвестных |

В текущих инструкциях есть соответствующие методы и ограничения. Это не наблюдение
поведения модели. Следующий уровень доказательства — реальные ответы с независимой
оценкой по этим критериям.

## Исполняемая проверка

Прямые вызовы `router.route` из корня текущей копии дали:

- «Какой инструмент для ответа на заявки?» → `['office-consult']`.
- «Напиши письмо клиенту» → `['office-firstwin']`.
- «Сколько будет 17 умножить на 19?» → `[]`.

Пять содержательных заметок присутствуют; десять локальных Markdown-ссылок knowledge
проверены на существование цели. `git diff --check` по owned-файлам прошёл.

Автотест, сравнивающий текст инструкции с её же формулировкой, не добавлялся: он не
доказывает полезность консультации. Актуальные продукты, все темы ИИ, автозагрузка
навыка и работа Claude этим проходом не проверены.
