Анна, предлагаю такой регламент для существующей CRM:

| Участок | Правило |
|---|---|
| Очередь | Сначала просроченные ответы, затем заявки с ближайшим сроком. При равном сроке — более ранняя заявка. |
| Ответственный | У каждой открытой заявки один ответственный. При передаче новый ответственный подтверждает приём. |
| Первый ответ | Ответить по существу; если данных недостаточно — запросить конкретное уточнение и назвать срок продолжения. |
| Следующий шаг | После каждого контакта записать действие, исполнителя и дату со временем. |
| Ожидание клиента | Сразу назначить дату повторного контакта. |
| Контроль | В начале и конце рабочего дня проверять заявки без ответственного, без следующего шага и с просрочкой. |

**Основное правило: у открытой заявки всегда есть ответственный и следующий шаг со сроком.** Срок первого ответа нужно согласовать с вашим рабочим графиком.

Какая у тебя CRM, откуда поступают заявки и сколько человек на них отвечают? По этим данным привяжем регламент к конкретным полям и фильтрам.
