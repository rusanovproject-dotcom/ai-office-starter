## Результат

Один локальный офис использует общий канон для Codex и Claude Code. Этапы коуча,
Директора и Риты завершаются после активации. Найм требует содержательного источника,
сохранённого результата пробы, критерия, оценки и подтверждения; для экспертной роли
нужен отдельный отчёт независимого проверяющего. Файлы и разные имена сами по себе
не доказывают компетенцию: содержание оценивает инициатор.

Восстановлены отдельные процедуры текстов, продаж и нишевого помощника. База Никиты
содержит пять переносимых заметок по контрактам офиса. Выбранное обращение и тон
соблюдаются; недоступный поиск не выдаётся за выполненный. Директор честно читает память
по задаче, Рита сохраняет разрешённые решения своей работы.

## Границы

Claude, смена Codex ↔ Claude, Windows/Linux и Codex Desktop отдельно не проверены.
Новая модельная проба каждого сотрудника и найма целиком не проводилась. Устойчивость
по одной выборке не измерена. CRM, внешние отправки, покупки и актуальные цены не
проверялись. Все данные синтетические; реальные офисы учеников и клиентские данные
не использовались. Финальный fingerprint hooks не проходил новую native trust-приёмку:
прямой bootstrap её не заменяет, обновлённые hooks требуют review клиента.

Основной том во время проверки исчерпал место. Неуспешные прогоны из-за ENOSPC не
считались поведенческими результатами; полный suite повторён на собственном временном
RAM-диске и прошёл. Удалены только временные кеши этого запуска, пользовательские
данные не очищались. Исходные незавершённые правки гайда в другой рабочей копии не
включены и не изменялись.
