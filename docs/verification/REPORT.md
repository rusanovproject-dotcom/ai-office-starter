## Что получилось

- Общий канон `AGENTS.md` и `.agents/skills`; Claude получает короткую импортирующую обёртку и воспроизводимую копию навыков. Ручная правка производной копии вызывает конфликт.
- Подтверждённые факты, цели по областям и персональные правила имеют канонические источники. Рабочий стиль меняет действия сотрудников; отказ и чужой субъект сохраняются правильно. Личные данные пользователя этой машины для разработки не использовались.
- Единый договор конечного результата, выбор проекта до роли, локальные инструкции подпапок, проверяемые полномочия и реестр имён/алиасов.
- Минимальный полный найм: задача → инструкции/источники/карточка/память → draft → реальная проба → подтверждённая активация. Сотрудники реализованы как роли в текущем чате; native subagents в пакет не входят.
- Независимое от желания модели обновление состояния через нативные адаптеры и явный launcher. Установка Git-гейта, snapshot и состояние выполняются последовательно; пользовательский индекс и коммиты не меняются.
- Обновление по хеш-манифесту с проверкой владельческих файлов, откатом при сбое и сохранением backup. Конфликт не стирает пользовательские инструкции, навыки или сотрудников.

## Ограничения

- **Claude model, discovery навыков моделью и переключение Codex ↔ Claude — SKIPPED по указанию владельца «клод не трогаем. его не тестим сейчас».** Прежний init-only SessionStart без авторизации — только lifecycle, не модельная приёмка. После указания Claude не запускался.
- Windows, Linux и Codex Desktop — SKIPPED; другие версии Python/CLI не проходили runtime-приёмку. Указанный в README Python 3.10+ — требование к синтаксису, проверена 3.14.6.
- Пустые HOME/CODEX_HOME не содержали личных инструкций/памяти Никиты. Стандартные материалы установленного CLI могли загружаться самим CLI. Авторизация передавалась временными symlink без чтения/печати содержимого; ссылки после проб удалены.
- Git-проверки используют синтетические локальные истории, public/unknown/private моделируются; реальная публикация и проверка доступа к чужим GitHub-репозиториям не выполнялись. ПД-гейт и текстовые правила не являются абсолютным ограничителем терминала.
- Один запуск на поведенческое условие, без статистического вывода. История чата хоста вне управления файловым офисом. Реальные CRM, отправка сообщений, публикация, деплой и миграция учеников не проверялись и не выполнялись.

ZIP содержит только 142 файла чистого шаблона, включая скрытые конфигурации. В нём нет .git, docs/tests, synthetic owner profiles, логов сессий, backup, секретов и symlink. Контрольная сумма и размер — в [release.json](release.json). Архив проверки и архив выдачи имеют одинаковые байты.
