# Этап 3 — Коуч по желанию

Отказ от коуча — `Этап 3: коуч (пропущен)` с минимальной разрешённой записью, без уговоров. Цели при этом остаются в me/goals.md.

Если коуч нужен, прочитай team/agents/atlas/core.md и текущие цели. Не собирай их заново. Уточни только желаемые сценарии, тон, частоту и имя, покажи короткий пример разговора. Настрой card по team/agents/_card-template.md: вектор — ссылка на конкретную цель me/goals.md, помогаю с — реальные задачи владельца, характер — согласованный выбор. При смене цели обновляй канон, а не старую запись журнала.

Создай memory/commitments.md, observations.md и log.md из шаблонов. Личные запреты действуют в памяти. В реестре отдельно имя/aliases и role; слово «коуч» не алиас. Покажи карточку, проверь `bash scripts/office/stage-check.sh 3`, затем активируй запись через registry.py. Проверка до активации требует status draft, после активации — active. Закрой этап после подтверждения примера человеком. Не обещай фоновое сообщение: роль отвечает в этом чате.
