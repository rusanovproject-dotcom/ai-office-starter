# Этап 3 — Коуч по желанию

Отказ от коуча — `Этап 3: коуч (пропущен)` с минимальной разрешённой записью, без уговоров. Цели при этом остаются в me/goals.md.

Если коуч нужен, прочитай team/agents/atlas/core.md и текущие цели. Не собирай их заново. Уточни только желаемые сценарии, тон, частоту и имя, покажи короткий пример разговора. Настрой card по team/agents/_card-template.md: вектор — ссылка на конкретную цель me/goals.md, помогаю с — реальные задачи владельца, характер — согласованный выбор. При смене цели обновляй канон, а не старую запись журнала.

Создай memory/commitments.md, observations.md и log.md из шаблонов. Личные запреты действуют в памяти. В реестре отдельно имя/aliases и role; слово «коуч» не алиас. Покажи карточку и выполни пробный разговор как настройку draft-роли. Не представляй её уже активным коучем.

Сохрани разрешённый результат пробы локально, например `results/coach-trial.md`, с критерием «выбран один следующий шаг, соблюдены обращение и тон». Если человек запрещает запись содержания, используй разрешённую обезличенную пробу; при отсутствии разрешённого доказательства оставь роль draft и этап открыт. Получи подтверждение результата человеком; не подставляй его сам. После подтверждения активируй штатно: `python3 scripts/office/hire.py activate --id atlas`, передав JSON через stdin. Нужны `task`, `output` (краткое резюме), `artifact` (относительный путь к существующему непустому результату), `criterion`, `assessment` (оценка по этому критерию), `confirmed: true`. Подтверждение из более раннего шага учитывай, не спрашивай повторно.

Только после успешной активации проверь `bash scripts/office/stage-check.sh 3`, затем закрой этап. Проверка требует status active; draft готовностью не считается. Не обещай фоновое сообщение: роль отвечает в этом чате.
